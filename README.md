# Макет корзины магазина

## Возможности

Этот скрипт позваляет добавлять и удалять набор из заданных *объектов(продуктов)* в корзину, выводить содержимое корзины и итоговую сумму с помощью заранее сделанных методов

## Методы

* addProduct(Product p)

Метод получает на вход продукт который нужно добавить и добавляет его в корзину

* removeProduct(String name)

Метод получает на вход название продукта который нужно удалить и удаляет его в из корзины

* printCart(Product p)

Метод выводит в консоль все товары и их стоимости пронумеровонным списком

* getTotal(Product p)

Метод выводит суммарную стоимость всех товаров в корзине
